## 4. 環境設計

| 環境       | Web             | API/DB                        | 用途                |
| ---------- | --------------- | ----------------------------- | ------------------- |
| local      | Vite dev server | Fastify + 一時SQLite          | 単体・結合開発      |
| test       | build preview   | 独立SQLite fixture            | 自動E2E             |
| staging    | HTTPS静的配信   | 常時稼働コンテナ + 永続SQLite | Push実機・配置確認  |
| production | HTTPS静的配信   | 常時稼働コンテナ + 永続SQLite | 7日間試用、本番利用 |

PWAとWeb Pushは安全なコンテキストが必要なため、localhost以外はHTTPS必須とする。stagingとproductionでVAPID鍵、DB、許可オリジンを分離する。

## 5. リリースゲート

- すべての必須機能要件F-001〜F-017に成功する受入シナリオがある。
- `localStorage`を消さない限り、更新・オフライン・API停止でタスク本文を失わない。
- APIリクエスト、DB、ログ、Push payloadにタスク本文が存在しない。
- 通知不達でもアプリ起動時に同じ処理対象が表示される。
- iOS Home Screen PWA、Android Chrome、PC Chrome/Edgeの実機確認結果を記録する。
- JSONバックアップから別のブラウザプロファイルへ復元できる。
- 既知の【要確認】事項をリリース判断表へ移し、採用・延期・却下を明示する。

## 6. 7日間試用の評価

| 指標                   | 取得方法                         | 継続判断の目安（【想定】） |
| ---------------------- | -------------------------------- | -------------------------- |
| 思いつき保存回数       | 端末内集計                       | 5件以上                    |
| 記録漏れの自己申告     | 試用前後質問                     | 減少                       |
| 受信箱処理率           | 分類済み / 全キャプチャ          | 60%以上                    |
| 今日の確認完了率       | 完了セッション / 開始セッション  | 70%以上                    |
| 通知なしでも再訪した日 | 日次ローカル記録                 | 3日以上                    |
| 放置タスクの決着率     | 完了・再期限・不要 / レベル2以上 | 50%以上                    |

集計は端末内で行い、MVPでは分析サーバーへ送信しない。
