# mvp-1.36.0 アプリ生成履歴IDを含むバックアップの復元

対象: F-017 / F-018 / NF-006。2026-11-03の添付JSON・エラー画像による復元失敗の修正。

- 通常の記録作成・分類変更では履歴IDにUUIDと操作名等を連結しているが、バックアップ復元だけが履歴IDをUUID限定で検査していた。アプリで正常に作ったデータをアプリ自身が復元できない不整合だった。
- 履歴IDは空でない文字列として扱い、重複・参照先・セッション所有の検査を維持する。その他のエンティティのUUID、チェックサム、日時・schema検査は変えない。履歴IDを書き換えず、履歴とセッションの参照を保持して復元する。
- ロジック変更のためPWAをmvp-1.36.0へ更新。保存schemaVersion 11、バックアップversion 1を維持し、既存のJSONをそのまま利用できるようにする。
- 合成データによる回帰検査2件と添付JSONの検査で、修正前のUUIDエラーを再現した。修正後は単体20件と添付JSONのローカル検査が成功。添付JSONの記録165件・タスク46件・確認139件・履歴465件を保持し、復元履歴1件を追加して再書出し・再検査できることを確認した。
- 添付原本は変更しない。実データの検査・復元はローカルの隔離環境だけで実行し、原本と本文をGit・本番サーバーへ送らない。Git管理する回帰テストは架空データのみを使う。
- 証跡: `dist/backup-1360/`（Git管理外）。
