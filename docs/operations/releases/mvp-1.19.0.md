# mvp-1.19.0 検証記録

## 変更範囲

- 全画面共通の「あとキュー」を10px相当から、同じ行の期限超過案内と同じ `0.8125rem`（標準13px）に変更。
- Kosugi、緑灰色、通常の太さ、字間、配置は維持。アプリ本体の変更はCSSの文字サイズ1行と版情報のみ。
- 保存形式、通知設定・予約、今日の確認の履歴保持ルールは変更なし。
- 複数画面共通の変更に対するリポジトリの版管理ルールに従い、表示・Web・API・パッケージを `mvp-1.19.0` / `1.19.0` に揃える。

## 検証

- 変更前の実ブラウザで、文字サイズの一致テストが `Expected: 13px / Received: 10px` で失敗することを確認してから実装。
- 320×640、360×450、412×760で同サイズ、横並び非干渉、入力画面のスクロール非増加を検証。320px幅のスクリーンショットも目視確認。
- 単体・結合: 61ファイル531件成功。
- lint、型検査、全ワークスペースbuild、配置成果物検査: 成功。
- E2E: ビルド終了後の単独再実行で39件すべて成功（`--workers=1 --trace retain-on-failure`）。
- 独立した読み取り専用レビュー: Critical・Important・Minorとも指摘0件。

最初の全E2Eでは、別のWeb buildが同じ配信成果物を更新している間に「今日の確認」の初期表示が1件タイムアウトした。アプリやテストの条件を変更せず、build完了後にE2Eを単独で再実行し全39件成功。検証同士の干渉を避けるため、E2E中は同じ `dist` を書き換える別ビルドを実行しない。

Pixel実機の表示は未確認。検証にはテスト専用データを使用し、利用者の端末データは変更しない。
