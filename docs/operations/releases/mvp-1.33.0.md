# mvp-1.33.0 日付入力の当日初期値

対象: F-007 / F-009 / F-010 / NF-010。2026-10-16の利用者依頼による修正。PWAのローカル修正版で、公開は未実施。

## 原因と修正

- 共通の期限入力にある薄い入力例が `例: 2026/08/10` に固定されていた。日付の実値が固定されていたわけではなく、候補画面の「日付を選ぶ」と今日の確認の「日付を変える」の初期値は空だった。
- 候補画面で日付指定を選ぶと、端末内設定のタイムゾーンで求めた当日を入力する。今日の確認も、日付変更を開いた時点の当日を表示する。日付だけの値をUTCの日付切り出しで求めない。
- 未編集の初期値は翌日に開き直すと更新し、手入力した値は保持する。入力例も当日にする。空欄からカレンダーを開く場合はその時点の当日を候補にし、入力途中・不正な日付は上書きしない。
- 詳細画面は既存の「保存済み期限を優先し、未設定なら当日」を維持する。初期表示やカレンダーの操作だけではタスクを保存せず、「期限なし」「まだ決めない」は確定操作まで維持する。
- PWA版を `mvp-1.33.0` へ更新した。Viteが生成するJSファイル名とService Workerの事前キャッシュ情報で更新を識別する。通知API・保存形式の変更はない。
