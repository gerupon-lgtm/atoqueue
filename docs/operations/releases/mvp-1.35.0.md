# mvp-1.35.0 受信箱の狭幅対応と本文リンク

対象: F-004 / F-021 / NF-008 / NF-009。2026-11-03のPixel 9aの表示報告と受信箱・メモのURLリンク依頼に対応する。

- 修正前の受信箱は、長いURLにより320pxの画面で文書幅2146pxとなることを合成データのブラウザ試験で再現した。タスク画面の対策は受信箱には適用されていなかった。
- 受信箱のページ・一覧・カードの列を縮められるようにし、本文・編集欄・タブ・ボタンは必要に応じて折り返す。横スクロールを隠して見えなくする方法は使わない。
- 未整理・メモ・不要の本文表示に既存のHTTP(S)リンク部品を使用する。1回の確認で新しいブラウザ画面へ開き、取消時は移動しない。未保存の編集内容・分類・保存形式・通知APIは変更しない。
- PWA版をmvp-1.35.0へ更新し、ハッシュ付きJS/CSSとService Workerの事前キャッシュも更新する。
- 検証証跡は `dist/inbox-1350/`。Pixel 9a実機の実際のCSS幅・文字設定は未取得のため、幅320/360/393/412/448pxと文字100/150/200%を組み合わせて検証する。
