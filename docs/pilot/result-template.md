| ---- | ------------- | -------- | ------------------ | ---- | ---------- | ---------------------- | ---- |
|      |               |          |                    |      | yes/no     |                        |      |

通知未着、拒否、ブラウザ非対応は失敗として隠さず記録する。その場合もアプリ内の今日の確認を完了できたかを記す。
